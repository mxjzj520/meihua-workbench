# 美化工作台

为 SillyTavern 制作状态栏和开场白的创作工具。

打开部署地址即可使用；也可通过 Edge、Chrome 或 Safari 添加到桌面/主屏幕。实际全屏表现取决于浏览器和系统。

作品、素材、聊天记录和 API 设置保存在使用者自己的浏览器中。更换浏览器、网址或清除网站数据前，请先导出备份。首次从本地 HTML 切换到网页版时，可通过“备份与恢复”导入。

需要在线 AI 功能时，请使用支持浏览器跨域访问的 HTTPS API 地址。网页不提供公共 API 密钥。离线可打开已缓存的工作台，AI 和外部素材仍需联网。

程序会在后台下载新版，并提示更新；只有点击更新后才重新打开页面。生成中请等待完成后再更新。
